Detected Anomalies

This tool detects the following network anomalies:

  • Port Scanning: Detects reconnaissance activity by identifying sources scanning multiple ports
  • SYN Flood: Identifies potential denial-of-service attacks using SYN packets
  • Data Exfiltration: Detects unusual outbound data transfers that may indicate data theft
  • C2 Beaconing: Identifies regular periodic communication patterns typical of malware
  • DNS Tunneling: Detects data exfiltration through DNS queries
  • ICMP Tunneling: Identifies covert channels using ICMP packets
  • Slowloris Attacks: Detects slow HTTP DoS attacks
  • Fragmentation Attacks: Identifies IP fragmentation-based attacks
  • Protocol Anomalies: Detects protocol misuse on standard ports
